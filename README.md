# TS Group Africa multipage website

## Included
- Home page
- About page
- Services page
- Contact page
- National properties page with cascading filters
- Nine province pages
- Individual dynamic property detail page
- 116 populated property records
- Property imagery displayed on every card and detail page
- Original-style bright green blended with deep green

## Upload
Upload all files and folders into `public_html`.

## Important data note
A large portion of the venue names were transcribed from the existing public TS Group catalogue. Some supplementary well-known South African venue records and representative images were included to deliver the requested 100+ functional entries. For an exact one-to-one migration of all original descriptions and media, import the site's WordPress XML/database/media export and replace `property-data.js` plus the remote image URLs.
